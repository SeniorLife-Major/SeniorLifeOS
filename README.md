# SeniorLife OS

An agentic assistant that helps senior citizens manage documents, healthcare, and government benefits, with family members in the loop.

## Repository layout


```
backend/     Python + LangGraph workflows, FastAPI server, document vault (PostgreSQL), tests, demo runner
frontend/    Web app (React / Next.js — Senior Mode and Family Mode), not started yet
deployment/  Docker Compose orchestration, entrypoint scripts, and container deployment configs
docs/        Project blueprints and design documents
```

- Backend setup and usage: [backend/README.md](backend/README.md)
- Docker deployment: [deployment/README.md](deployment/README.md)
- Blueprints: [docs/](docs/)
